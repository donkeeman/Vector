# Vector Persona/근거응답 고도화 계획 (Interview 연계)

작성일: 2026-03-24  
대상 프로젝트: `Vector` (개인 프로젝트)  
목적: 실제 개선 작업 계획 + 면접에서 답변 가능한 근거 확보

---

## 1) 문제 정의

- 현재 Vector는 페르소나 프롬프트와 톤 정규화가 있으나, 태스크/상황에 따라 말투나 캐릭터 강도가 흔들릴 여지가 있음.
- "최신 정보" 질문에 대해 근거 없는 단정이 나올 위험이 있음.
- 면접에서 "어떻게 일관성/정확성을 보장했는지"를 수치와 증거로 설명할 재료가 아직 부족함.

---

## 2) 목표

1. 페르소나 일관성(말투/캐릭터 규칙) 유지율을 측정 가능하게 만든다.
2. 설명/교정 답변에 근거를 붙이는 경로를 만든다. (1차는 벡터 검색 없이)
3. "최신성" 질문은 별도 라우팅으로 보수 응답하도록 만든다.
4. 결과를 면접 답변 자료(질문-근거-수치)로 바로 전환 가능하게 남긴다.

---

## 3) 범위

### 포함
- Persona 계약(규칙) 명문화
- 톤/페르소나 회귀 테스트 추가
- 근거응답 RAG-lite(키워드 검색 기반) 도입
- 최신성 질문 라우팅 규칙 정의
- 평가셋 기반 품질 측정

### 제외 (이번 사이클)
- 벡터 DB/임베딩 기반 검색
- 전 도메인 자동 크롤링 인덱싱
- 완전 자동 fact-check 파이프라인

---

## 4) 작업 스트림

### A. Persona Consistency Hardening

- 페르소나 규칙 문서화:
  - 금지 표현(존댓말/무개성 답변)
  - 필수 요소(라이벌 톤, 짧고 명확한 코칭)
- 출력 검사:
  - 존댓말 패턴 검사
  - 캐릭터 키워드/톤 검사
- 회귀 테스트:
  - 고정 질문셋(최소 20개)으로 톤 일관성 측정

완료 산출물:
- 페르소나 규칙 문서 1개
- 자동 검사/테스트 결과 로그
- 실패 케이스 before/after 샘플

### B. Grounded Answer (No-Vector First)

- 최소 스키마로 지식 저장:
  - `documents`
  - `chunks`
  - `qa_logs`
- 적용 경로:
  - `teach`
  - `direct_question`
- 응답 규칙:
  - 답변 + 근거 요약 + 출처(1개 이상)
  - 근거 부족 시 단정 금지 문구

완료 산출물:
- 도메인 2개(DB/OS) 문서 인덱싱
- 근거 포함 답변 로그

### C. Freshness Routing (최신성 분리)

- 질문 분류:
  - 개념형(내부 지식 우선)
  - 최신형(버전/릴리즈/변경점)
- 최신형 질문 처리:
  - "최신 정보 확인 필요"를 기본 정책으로 응답
  - 추후 공식 문서 allowlist 검색으로 확장 가능하게 인터페이스만 정의

완료 산출물:
- 질문 분류 규칙
- 최신성 fallback 응답 템플릿

### D. Interview Artifact Pack

- 아래 4가지를 한 번에 정리:
  - 무엇을 구현했는지 (기능)
  - 왜 그렇게 했는지 (의사결정)
  - 결과가 어땠는지 (지표)
  - 한계와 다음 단계

완료 산출물:
- 면접용 1페이지 요약
- 예상 질문별 근거 링크

---

## 5) 지표 (면접에서 말할 수 있는 최소 정량)

- `persona_consistency_rate`: 고정 질문셋에서 페르소나 규칙 통과 비율
- `citation_coverage`: 답변 중 출처 포함 비율
- `unsupported_claim_rate`: 근거 없이 단정한 답변 비율
- `fallback_rate`: "추가 확인 필요" 응답 비율

초기 목표:
- `persona_consistency_rate >= 95%`
- `citation_coverage >= 80%`
- `unsupported_claim_rate <= 10%`

---

## 6) 일정 (2주 예시)

- 1~2일: Persona 규칙 문서화 + 검사기 추가
- 3~5일: RAG-lite 스키마/인덱싱/검색 경로 추가
- 6~7일: `teach/direct_question` 연동
- 8~9일: 최신성 라우팅/보수 응답 정책 추가
- 10~12일: 평가셋 실행 + 지표 계산
- 13~14일: 면접 아티팩트(요약/질문답변) 작성

---

## 7) 면접 답변용 핵심 문장 (과장 방지 버전)

- "처음 아이디어와 요구사항은 제가 잡고, 구현은 AI 도구를 활용해 빠르게 진행한 뒤 테스트/수정은 제가 반복했습니다."
- "Vector는 아직 개인 프로젝트라 프로덕션 규모는 아니지만, 페르소나 일관성과 근거응답을 지표로 관리하는 방향으로 고도화 중입니다."
- "RAG는 벡터부터 시작하지 않고, 키워드 기반 RAG-lite로 먼저 정확성/운영 복잡도를 검증한 뒤 확장하려고 합니다."
